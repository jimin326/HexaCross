## ✅ 남서쪽 진입부: 중앙대로 서면 → 연산교차로 (완료)

### 차로 구성

들어오는 구간: 편도 3차로

```
[펜스] BRT1 ║ 일반1 │ 일반2 ║ 인도
```

정지선 앞: 편도 7차로 + 우회전 연결로

```
[펜스] BRT1 │ BRT2 ║ 일반1 │ 일반2 ║ 일반3 │ 일반4 │ 일반5 ║ (섬) 우회전 연결로
       교대 │ 안락 ║ 교대  │ 교대  ║ 안락  │안락·터널│ 연산터널║ → 광안리 (서행)
```

| 차로 | 가는 곳 |
|---|---|
| BRT 1 (버스전용) | 교대 (중앙대로 동래) |
| BRT 2 (버스전용) | 안락 (반송로) |
| 일반 1, 2 | 교대 (중앙대로 동래) ← AV |
| 일반 3 | 안락 (반송로) |
| 일반 4 | 안락 (반송로), 연산터널 (고분로) |
| 일반 5 | 연산터널 (고분로) |
| 우회전 연결로 (섬 분리, 신호 없음, 서행) | 광안리 (월드컵대로 남쪽) |
| — | 법원·검찰청 (월드컵대로 사직): 좌회전 금지 |

- BRT는 파란 이중선으로 일반 차로와 분리 (넘어갈 수 없음), BRT 1·2 사이는 파란 점선
- 교대 차로(1·2)에 분홍 노면색깔유도선
- ×가 붙은 좌회전 화살표는 금지 전 옛 표시를 무효 처리한 것으로 보임 (옛 글씨 지운 흔적 있음)

### 거리 (대략값, 그림자로 항공사진 측정 불가)

- 일반 2차로와 3차로 사이 실선(차로 변경 금지): 정지선 약 30m 전부터

- BRT: 1차로로 오다가 정지선 앞에서 2차로로 갈라짐 (지민 확인). BRT 쪽에 좌회전 화살표가 보여 버스만 좌회전 가능할 가능성 (확인 필요)
- 신호: 차로 그룹별로 신호등이 따로 있는 것으로 보임 (지민 확인) → 6현시 가정 재검토 필요, CCTV로 확인
- 정지선 앞 차로 (지민 로드뷰 판독, 중앙 → 인도):

```
[펜스] BRT1 ║ 일반2 │ 일반3 ║ 일반4 │ 일반5 ║ (섬) 우회전 연결로
       시청 ║  수영  │  수영  ║  시청  │  시청  ║ → 거제천 (법원·검찰청, 잠정)
```

|---|---|---|

| — | 반송로, 고분로 | 좌회전 금지 |

- 신호: 신호등 지지대에 "버스신호" 별도 신호등 있음 (버스와 일반 차량 신호 순서가 다름). 좌회전 금지 표지 아래 보조표지 (버스 제외로 추정, 글씨 판독 불가)

- 진입 방향별 동시신호 6현시: 한 번에 한 도로만 녹색, 그 도로의 모든 이동류 동시 진행 (legs 순서 N → NE → E → S → SW → W)
- 녹색: 간선 25초, 반송로·고분로 15초 / 황색 3초 / 전적색 2초 / 주기 160초 / 매 판 시작 시점 무작위
- 교통량은 이 신호 처리 능력의 60~70%로 역산 (실측의 약 1/3)
- 시청 인근: 같은 방식 95초. 나머지 작은 신호: netconvert 기본 90초
- 우회전 연결로: 신호 없음, 합류 지점 양보
