# 프로젝트 규칙 요약

HexaCross는 성균관대학교 「자율주행인공지능및제어」 수업(2026년 2학기)의 팀 프로젝트다.
이 문서는 수업 자료, 컨설팅 FAQ, 조교 Q&A 답변(2026-11-17 ~ 11-27)에서 정해진 규칙을 한곳에 모으고, 이 저장소가 각 규칙에 어떻게 대응하는지 적는다.
저장소의 다른 문서에서 "프로젝트 규칙", "조교 답변"이라고 하면 이 문서의 항목을 가리킨다.

수업 자료 원문은 [수업 저장소](https://github.com/bmil-ssu/Artificial-Intelligence-and-Control-for-Autonomous-Driving/tree/main/project_materials)에 있다.

## 주행할 때 (평가 · 데이터 수집)

| # | 규칙 | 이 저장소 |
|---|---|---|
| R1 | 최종 AV는 **학습한 신경망 하나**가 행동을 낸다. 주행 중에 규칙이나 다른 모델이 개입하면 안 된다 | 루프 B 모델(RL ~ RL4)은 단일 신경망이다. 규칙은 모방학습 정답 보정과 보상에만 쓴다 |
| R2 | 위험 신호가 오면 출력에 보정값을 켜는 구조는 안 된다. 보상으로 학습한다 | 잔차 보정 정책은 초기 실험(res1 ~ res9)에서만 시험했고 채택하지 않았다 |
| R3 | 정책 출력(행동)을 환경이 강제로 바꾸면 안 된다. 예: 가속 명령을 제한속도에서 자르기 | 차량 성능 최고속도(`EGO["max_speed"]` 27.78 m/s)에서만 자른다. 제한속도 초과는 `overspeed_penalty`(0.5)로 감점한다 |
| R4 | 차로 변경 안전 검사(목표 차로 간격이 부족하면 실행 안 함)는 써도 된다 | 쓰지 않는다 (`lane_change_safety.enabled = False`) |
| R5 | SUMO 자동 안전 제동 · 자동 차로 변경은 끈다 (AV가 직접 운전) | `setSpeedMode(ego, 0)`, `setLaneChangeMode(ego, 0)` (`env/sumo_env.py`) |

## 관측 (신경망 입력)

| # | 규칙 | 이 저장소 |
|---|---|---|
| O1 | **차로 단위 경로 안내는 넣지 않는다.** 예: 차로마다 "경로를 따라가려면 몇 번 바꿔야 하는지" | `lane_route_info = False`. 차로 5칸은 차로가 있는지만 알려 준다 |
| O2 | 큰 틀의 경로 정보는 괜찮다. 예: 다음 갈림길까지 거리와 방향 | 다음 교차로의 회전 각도 · 거리(`route_turn`), 목표까지 남은 거리 |
| O3 | 사람이 볼 수 없는 정보로 돕는 관측은 피한다. 예: 교차로 상충 차량 예측 | `junction_foes.enabled = False`. 남은 신호 시간도 관측에 없다 |

노면 화살표 관측(`lane_arrows`, 15칸)은 운전자가 정지선 앞에서 보는 도로 표시라 넣었다. 이 항목은 조교에게 따로 확인받지 않았다.

## 학습할 때

| # | 규칙 | 이 저장소 |
|---|---|---|
| L1 | 모방학습(BC)으로 사전 학습한 뒤 PPO로 이어 학습해도 된다 | BC → DAgger → PPO |
| L2 | PPO 중에 전문가 데이터로 BC 보조 손실을 함께 써도 된다 | 모방 손실 가중치 1.0 → 0.2 |
| L3 | BC · DAgger 전문가로 규칙 기반 운전자를 써도 된다 | 전문가는 SUMO 운전 모델(Krauss, LC2013)이고, 학습 데이터의 정답만 규칙으로 보정했다 (`tools/rl/relabel_*.py`) |
| L4 | 전문가가 학생 관측에 없는 시뮬레이터 정보를 써도 된다. 평가 주행은 신경망 단독이어야 한다 | 전문가는 경로와 본선 차를 안다. AV는 56차원 관측만 본다 |
| L5 | 보상 계산에 시뮬레이터 내부 정보를 써도 된다 | 충돌까지 시간(TTC), 앞차 간격 등을 보상에 쓴다 |
| L6 | 사람이 실패 구간을 골라 그 구간만 학습하는 방식은 확인되지 않았다 | 쓰지 않는다. 대신 충돌 · 신호 위반 약 12초 전 상태를 자동으로 저장해 새 에피소드의 30%를 거기서 시작하고, 전체 경험으로 갱신한다 |

## 평가 · 데이터

| # | 규칙 | 이 저장소 |
|---|---|---|
| E1 | 충돌률 5% 미만. 순수 충돌만 센다 (차로 오류 등은 따로) | 최종 모델 RL4: 960회 중 충돌 4회 (0.42%) |
| D1 | 주행 데이터 10^7 transition 이상. 수집한 전체 데이터 기준이며 최종 정책 데이터만으로 채워도 된다 | 10,647,162 transition (3,600 에피소드) |
| D2 | 모든 행에 시뮬레이터 상태(AV 위치 · 속도 · 차로, 주변 차량 등)가 있어야 한다 | 모든 행에 `state`가 있다 (`DATA_FORMAT.md` 3절) |
| D3 | 수업 기본 수집 항목을 모두 포함한다 | `DATA_FORMAT.md` 0절 대조표 |
| D4 | 문자열 컬럼은 학습에 쓰지 않으면 괜찮다 | 모든 컬럼을 숫자로 저장하고 번호표를 `meta.json`에 둔다 |
