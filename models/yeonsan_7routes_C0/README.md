# 연산교차로 7경로 모델 `C0` (PPO 강화학습)

> 2026-11-18 · 학습·평가: 호섭 (Claude Code로 진행) · 브랜치 `train/yeonsan-6way`

연산교차로(부산 6지 신호교차로)를 지나는 경로 7개를 한 모델로 운전하도록 **PPO 강화학습**으로 학습한 모델입니다.
**모방학습(BC)은 쓰지 않았습니다.** 사람이나 규칙의 운전을 따라 하지 않고, AV가 SUMO에서 직접 달려 보고 받은 보상으로만 배웠습니다.

> **2026-11-19:** 관측 기본값이 56차원(관측 거리 100 m, 노면 화살표, 교차로 내부 관측)으로 바뀌었습니다. 이 모델을 돌리려면 `env/mdp_config.py`의 `OBSERVATION`에서 `visibility` 50, `lane_arrows.enabled` False, `internal_lane_obs` False로 되돌리세요. 지금 최고 모델은 `models/yeonsan_7routes_BC`(모방학습)입니다.

| 파일 | 내용 |

| `run_patch.json` | 이 모델의 마지막 학습 회차 설정 (seed, 보상 덮어쓰기, 스텝 수) |

## 성적 (경로마다 30회, 모두 210회)

| 경로 | 완주 | 충돌 | 신호 위반 | 차로 갇힘 |
|---|---|---|---|---|
| S→W→회전교차로→W→E (3.1 km, 연산교차로 2번) | 11 | 0 | 2 | 17 |
| N→S (교대 → 신리) | 25 | 0 | 5 | 0 |
| NE→SW (안락 → 시청) | 21 | 4 | 5 | 0 |
| E→W (연산터널 → 종합운동장) | 1 | 0 | 2 | 27 |
| S→N (신리 → 교대) | 27 | 0 | 0 | 3 |
| SW→N (시청 → 교대) | 23 | 7 | 0 | 0 |
| W→E (종합운동장 → 연산터널) | 28 | 2 | 0 | 0 |
| **합계** | **136 (65%)** | **13 (6.2%)** | **14 (6.7%)** | **47 (22%)** |

- 경로 5개는 70~93% 완주합니다. E→W와 회전교차로 경로는 정지선 앞에서 맞는 차로를 고르지 못해 대부분 "차로 갇힘"으로 끝납니다.
- 충돌은 대부분 같은 자리에서 납니다. 신호 교차로를 막 지난 곳에서 왼쪽 차로로 옮기다가, 교차로 안에서 그 차로로 들어오던 차와 부딪힙니다. 지금 관측은 교차로 안에 있는 옆·뒤 차를 못 봅니다. 자세한 내용은 아래 "다음에 할 일"에 있습니다.

## 환경

- **지도:** 학습 지도(연산교차로 주변 OSM 도로망). 연산교차로 중심 100 m는 차로 조사 자료대로 다시 지은 정밀 모델입니다(`env/maps/yeonsan_x6.json`, 자료 대조 188/188).
- **신호:** 연산교차로는 동시 녹색 6현시(주기 120초)입니다. 서로 안 엇갈리는 차로끼리 함께 녹색이며, 가정값입니다(`env/maps/README.md`).
- **교통:** 2025년 부산시 교통조사 실측 OD의 50%입니다. 100%로 올리면 상류 도로가 막혀서 쓰지 못했습니다. AV 관측 범위(앞뒤 50 m) 안에 평균 5대가 있고, 시간의 68%는 앞차가 있는 환경입니다.
- **경로:** `tools/rl/routes7.py`의 7개입니다. 에피소드마다 같은 확률로 하나를 고르고, 한 에피소드는 최대 3,000스텝(1,500초)입니다.

## 관측 · 행동 · 보상 (프로젝트 공지 준수)

- **관측 41개** (`DATA_FORMAT.md` 4절)
  - 내 속도, 5개 차로의 앞뒤 차 거리·속도차, 차로 유무, 차로별 밀도
  - 다음 신호 교차로의 진입 도로별 신호 6개, 정지선 거리
  - 목표까지 남은 거리, 큰 틀의 경로 안내(다음 교차로 회전 각도·거리)
  - **어느 차로로 가야 하는지는 알려 주지 않습니다.**
- **행동 2개:** 가감속, 차로 변경(왼쪽/유지/오른쪽)
- **보조 규칙 없음:** 차로 변경 안전 검사와 교차로 상충 차량 관측은 껐습니다.
- **보상**

| 항목 | 값 |
|---|---|
| 목표 쪽 진행 | + (스텝당 최대 0.1) |
| 완주 | +2 |
| 충돌 | −50 |
| 신호 위반 | −10 |
| 차로 갇힘 | −10 |
| 목표 도로로 안 이어지는 차로 | 스텝당 최대 −0.2 |
| 충돌 3초 전 위험 | −0.3 |
| 신호 앞 급제동 | −0.1 |

## 어떻게 만들어졌나 (이어 학습 순서)

| 회차 | 이름 | 무엇을 바꿨나 | 스텝 |
|---|---|---|---|
| 0 | G1 | 처음부터 PPO, 시청 → 교대 한 경로 | 60만 |
| 1 | F0 | 연산교차로 정밀 모델 고친 지도 | 4.1만 |
| 2 | R2 | 7경로를 섞어서 (main 병합 전 환경) | 11만 |
| 3 | M2 | main 병합 환경(실측 교통 50%), 예전 6현시 신호 | 40만 |
| 4 | N1 | 동시 녹색 신호로, 충돌 감점 −20 | 40만 |
| 5 | P1 | 교차로 앞 차로 변경 금지 구간 추가 | 40만 |
| 6 | Q2 | 차로 정보 범위 300 m, 충돌 −50 (공지 위반이라 중단) | 35.8만 |
| 7 | **C0** | **공지 준수 설정** (위 "관측·행동·보상") | 50만 |

- 3~6회차에는 지금은 끈 도움 요소가 켜져 있었습니다. 차로 단위 경로 안내 관측, 차로 변경 안전 검사, 상충 차량 관측입니다. C0는 그 회차의 가중치에서 출발했지만, 마지막 50만 스텝과 평가는 모두 공지 준수 설정입니다.
- 처음부터 공지 준수 설정으로만 학습한 모델이 필요하면 다시 학습해야 합니다.

## 다시 돌리기

```bash
# 평가 (경로마다 10회)
python tools/rl/eval_routes.py models/yeonsan_7routes_C0/model.pt <학습 지도 폴더> 10 out.json

# 이 모델에서 이어 학습
INIT_MODEL=models/yeonsan_7routes_C0/model.pt TIMESTEPS=500000 LANE_PLAN_RANGE=300 \
REWARD_PATCH='{"collision_penalty": 50.0, "red_light_penalty": 10.0, "ttc_penalty": 0.3, "ttc_threshold": 3.0, "blocked_penalty": 0.0, "goal_lane_weight": 0.2, "wrong_lane_penalty": 10.0, "signal_brake_penalty": 0.1, "foe_conflict_penalty": 0.0}' \
python tools/rl/train_routes.py my_run 0

# 주행 영상 (7경로)
xvfb-run -a python tools/rl/record_routes.py models/yeonsan_7routes_C0/model.pt <학습 지도 폴더> videos/C0 ego_0,ego_1,ego_2,ego_3,ego_4,ego_5,ego_6
```

- `<학습 지도 폴더>`는 `train.py`나 `train_routes.py`가 만든 SUMO 폴더(`env/sumo`)입니다.
- 한 경로만 보려면 `env/road_config.py`의 `EGO["routes"]`(주석에 7경로 예시)를 바꾸고 `python test.py models/yeonsan_7routes_C0/model.pt`를 실행합니다.
