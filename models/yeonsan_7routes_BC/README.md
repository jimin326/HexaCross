# 연산교차로 7경로 모델 `BC` (모방학습 + DAgger + 앙상블 증류)

> 2026-11-19 · 학습·평가: 호섭 (Claude Code로 진행) · 브랜치 `train/yeonsan-6way`

연산교차로(부산 6지 신호교차로)를 지나는 경로 7개를 한 모델로 운전합니다. **모방학습**으로 만든 모델이고, 같은 경로에서 강화학습만으로 만든 모델(`models/yeonsan_7routes_C0`)보다 완주가 20%p 높습니다.

- **전문가:** SUMO의 운전 모델이 AV를 직접 몰게 했습니다.
- **학생:** 이 모델은 AV 관측만 보고 전문가 행동을 따라 하도록 배웠습니다.

## 성적 (경로마다 80회, 처음 보는 교통 시드 4개, 결정적 정책, 모두 560회)

| 경로 | 완주 | 충돌 | 신호 위반 | 차로 갇힘 |
|---|---|---|---|---|
| S→W→회전교차로→W→E (3.1 km) | 59 | 3 | 0 | 18 |
| N→S | 73 | 2 | 5 | 0 |
| NE→SW | 56 | 4 | 0 | 20 |
| E→W | 62 | 7 | 2 | 9 |
| S→N | 76 | 3 | 1 | 0 |
| SW→N | 71 | 3 | 5 | 1 |
| W→E | 79 | 1 | 0 | 0 |
| **합계** | **476 (85.0%)** | **23 (4.1%)** | **13 (2.3%)** | **48 (8.6%)** |

시간 초과는 0회입니다. 같은 환경에서 C0는 완주 65%, 충돌 6.2%, 신호 위반 6.7%, 차로 갇힘 22%였습니다.

**목표(완주 90%, 충돌 1%)에는 아직 못 미칩니다.**

- 남은 실패의 절반은 회전교차로 경로와 NE→SW의 차로 갇힘입니다.
- 충돌은 대부분 차로를 바꾸다가, 옆 차로 뒤에서 더 빨리 오는 차와 부딪히는 경우입니다.
- 평가 표본(교통 시드)에 따라 완주가 81~90%, 충돌이 2~6%로 오르내립니다.

## 어떻게 만들었나

### 1. 전문가 데이터
- AV를 SUMO 운전 모델(Krauss 차량 추종, LC2013 차로 변경)에 맡겼습니다. 전문가는 신호, 안전거리, 경로에 맞는 차로를 지킵니다.
- 그동안 AV 관측(아래 56개)과 SUMO가 실제로 한 행동을 기록했습니다.
  - 가감속 = 속도 변화 ÷ 0.5초
  - 차로 변경 = 차로 번호 변화
- 전문가의 운전자 실수(sigma)는 껐습니다. 기본값 0.5에서는 이유 없이 감속하는 행동이 정답에 섞입니다.
- 7경로 800회를 모았고, 전문가는 97% 완주, 충돌 0이었습니다.
- 도구: `tools/rl/expert_collect.py`

### 2. 모방학습 (BC)
PPO와 같은 정책 신경망(`HybridActorCritic`, 256×256)을 학습했습니다. 그래서 `PPO.load`, `test.py`로 그대로 읽힙니다.

| 대상 | 손실 |
|---|---|
| 가감속 | 다음 스텝 속도(m/s) 차이의 제곱. 앞차가 가깝거나 적색 정지선이 가까우면 가중치 5배 |
| 차로 | 교차 엔트로피 (왼쪽/유지/오른쪽, 변경 클래스 가중치 8) |

**교사 보정**은 SUMO 전문가를 조금 더 조심스럽게 만든 것입니다. 결과를 가장 크게 바꾼 부분입니다.

- **앞차 여유 2 m:** SUMO는 최소 간격(2.5 m) 바로 그 자리에 멈춥니다. 같은 자리를 노리던 학생이 몇십 cm만 넘어도 충돌로 처리됐습니다. 그래서 "최소 간격보다 2 m 앞에서 멈추는 Krauss 안전 속도"로 정답 속도를 깎았습니다. 이것만으로 완주가 3%에서 84%로 올랐습니다.
- **적색 정지선:** 내 신호가 적색이면 "정지선 1 m 앞에서 설 수 있는 속도"로 정답을 깎았습니다. SUMO의 "이미 못 서면 그냥 지나간다" 규칙이 정답에 들어오는 것을 막아서, 신호 위반이 줄었습니다.

도구: `tools/rl/bc_train.py`

### 3. DAgger
- 학생이 운전하다 들어간 상황(전문가는 가지 않는 상황)에서, SUMO에게 "이 상황이면 어떻게 했을지"를 물어 정답을 더했습니다.
  - 가감속 정답: `getSpeedWithoutTraCI`
  - 차로 정답: `wantsAndCouldChangeLane`
- 이 모델에는 초기 2회분만 들어갔습니다. 더 잘하는 학생으로 모은 DAgger 차로 정답은 회전교차로 경로를 망가뜨려서 뺐습니다.
- 도구: `tools/rl/dagger_collect.py`

### 4. 위험 상황 보강
전문가가 차로를 바꾼 장면을 복사했습니다. 복사본에는 바꾸려는 쪽 차로에 "8 m 안의 더 빠른 뒤차" 또는 "3 m 안의 앞차"가 있게 값을 바꾸고, 정답을 "유지"로 두었습니다. SUMO도 그 상황에서는 바꾸지 않습니다. 앙상블 구성원 절반에 썼습니다.

### 5. 앙상블 → 증류
- 같은 데이터로 학습해도 모델마다 실제 운전 성적이 크게 갈렸습니다. 같은 평가에서 완주가 71~91%까지 차이 났습니다.
- 그래서 8개를 학습해 평균을 냈습니다. 가감속은 평균, 차로는 확률 평균입니다.
- 이 평균 출력을 정답으로 모델 하나를 다시 학습했습니다(증류).
- 증류한 모델의 성적은 앙상블과 거의 같습니다(280회 기준 완주 82.5% 대 84.3%, 충돌 3.9% 대 4.6%).
- 도구: `tools/rl/distill.py`

**강화학습(PPO)으로 이어 학습해 봤지만 나빠졌습니다.** 모방학습 모델에서 PPO를 돌리면 탐험 중에 차로 선택이 흐트러져, 20만 스텝에서 완주가 91%에서 74%로 떨어졌습니다. 그래서 이 모델은 모방학습만 거쳤습니다.

## 관측 56 · 행동 2 (`DATA_FORMAT.md` 4절)

- 0–40: C0와 같습니다(내 속도, 5개 차로 앞뒤 차, 차로 유무, 밀도, 진입 도로별 신호 6개, 정지선 거리, 목표 거리, 다음 교차로 회전 각도).
  - 관측 거리는 100 m입니다(C0는 50 m).
  - 교차로 안에서도 곧 들어갈 도로 기준으로 관측합니다.
- **41–55 노면 화살표:** 5개 차로마다 다음 신호 교차로 정지선에서 좌회전·직진·우회전이 가능한지입니다.
  - 운전자가 보는 노면 표시이고, 내 경로가 어느 차로로 가야 하는지는 알려 주지 않습니다.
  - 이 관측이 없을 때는 E→W 같은 경로가 대부분 차로 갇힘으로 끝났습니다.
- 행동은 가감속, 차로 변경(왼쪽/유지/오른쪽)입니다. 주행 중 보조 규칙(차로 변경 안전 검사, 상충 차량 관측)은 없습니다.

### 프로젝트 공지와 관련해 팀이 확인할 것
1. **노면 화살표(41–55):** 도로 표시이지 차로 단위 경로 안내는 아니라고 보고 넣었습니다(호섭 결정). 공지 "어떤 차선으로 주행해야 하는지 등 세밀한 정보 금지"에 해당하는지 확인해 주세요.
2. **전문가 데이터:** 교사(SUMO 운전 모델)는 경로를 알고 운전합니다. 하지만 학습된 AV는 위 관측만 보고 운전합니다. 저장소에는 원래 모방학습 틀(`train_bc.py`, `collect_pomdp_data.py`)이 있습니다.

## 다시 만들기

모든 명령은 저장소 루트에서 실행합니다. libsumo가 있으면 자동으로 씁니다.

```bash
# 1) 전문가 데이터 (SUMO 4개 병렬, 경로당 약 115회, 약 5분)
N_WORKERS=4 SEED=21 python tools/rl/expert_collect.py data/expert_e800 200
```

```bash
# 2) BC 1개 (학생). DAgger 데이터는 학생으로 운전하며 모음
python tools/rl/bc_train.py data/bc_a.pt data/expert_e800.npz
```

```bash
N_WORKERS=4 SEED=101 LANE_LABEL=wants python tools/rl/dagger_collect.py data/bc_a.pt data/dg1 60
```

```bash
# 3) 앙상블 구성원 (시드만 바꿔 여러 개, 절반은 AUG_LC=2)
SEED=1 LANE_FROM_DG=1 EPOCHS=15 LC_WEIGHT=8 python tools/rl/bc_train.py data/m1.pt data/expert_e800.npz data/dg1.npz
```

```bash
SEED=2 AUG_LC=2 LANE_FROM_DG=1 EPOCHS=15 LC_WEIGHT=8 python tools/rl/bc_train.py data/m2.pt data/expert_e800.npz data/dg1.npz
```

```bash
# 4) 증류 (ENS 파일 = 구성원 경로를 한 줄에 하나씩)
python tools/rl/distill.py data/members.ens models/my_bc/model.pt data/expert_e800.npz data/dg1.npz
```

```bash
# 평가 (경로마다 20회)
SEED=905 python tools/rl/eval_routes.py models/yeonsan_7routes_BC/model.pt env/sumo_expert/w0 20 out.json
```

이 모델의 구성원 8개는 다음 데이터로 학습했습니다.

- 전문가 800회
- DAgger 2회분(약 7만 스텝, 차로 정답 포함)
- 그중 4개에는 위험 상황 보강

증류에는 전문가 2,400회와 DAgger 3회분의 관측을 썼습니다. 데이터 파일은 용량 때문에 저장소에 넣지 않았습니다.
