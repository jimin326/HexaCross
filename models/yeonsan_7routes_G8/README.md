# 연산교차로 7경로 모델 G8 (모방학습 + DAgger 5회, 앙상블 8개)

> 2026-11-20 · 브랜치 `traffic/yeonsan-capacity`

이 모델은 늘린 교통량 지도에서 다시 학습한 앙상블입니다. 지도에는 주변 신호 수요 분배와 실제 버스(BRT 포함)가 들어 있습니다.

- **구성:** 서로 다른 신경망 8개입니다. 시드 버그를 고친 뒤 학습해서, 8개가 실제로 모두 다릅니다.
- **운전 방식:** 가감속은 8개의 평균을 씁니다. 차로는 8개 확률의 로그 평균에서 가장 큰 쪽을 고릅니다.

## 성적 (결정적 정책, 경로마다 60회 = 시드 921~924 × 15회)

| 교통량 (실측 대비) | 평가 | 완주 | 충돌 | 신호 위반 | 차로 갇힘 | 시간 초과 |
|---|---|---|---|---|---|---|
| **0.7 + 버스 (지금 기본값)** | 420회 | **96.7%** | **0.48%** | 1.4% | 1.4% | 0 |
| 0.85 + 버스 | 420회 | 93.8% | 3.1% | 1.9% | 1.0% | 0.2% |

같은 지도와 같은 시드에서 이전 모델과 비교하면 다음과 같습니다.

| 모델 | 0.7 완주 / 충돌 | 0.85 완주 / 충돌 |
|---|---|---|
| final (16개, 실제 4개) | 95.5% / 1.9% | 90.2% / 6.4% |
| E8 (DAgger B4까지, 8개) | 96.7% / 1.9% (210회) | 92.6% / 2.9% |
| **G8 (DAgger B5까지, 8개)** | **96.7% / 0.48%** | **93.8% / 3.1%** |

- 0.7과 0.85 모두 프로젝트 기준(완주 90% 이상, 충돌 5% 미만)을 넘습니다.
- 0.7에서는 팀 목표인 충돌 약 1%도 만족합니다.
- **0.85에서 남은 충돌 (13회):**
  - 대부분 E→W(7회)와 N→S(4회)에서 났습니다.
  - E8로 충돌을 분석해 보니 약 60%는 교차로 안 충돌이었습니다. 같은 차로에서 좌회전하려고 교차로 입구에 서 있던 차의 뒷부분처럼, 다른 연결 차로에 있어서 관측의 앞차로 잡히지 않는 차와 부딪힙니다.
  - 나머지는 차로를 바꾸다 옆 차와 부딪힌 경우입니다.
- 원자료: `eval.json`

## 어떻게 만들었나

`models/yeonsan_7routes_final/README.md`와 같은 방법에, 새 지도에서 모은 DAgger 데이터 두 번을 더했습니다.

1. **DAgger B4 (21만 스텝):**
   - 학생: final 앙상블
   - 수집 지도: 0.85 지도 워커 2개, 0.7 지도 워커 2개
   - 차로 정답: `LANE_LABEL=best`
2. **E8:** 지금까지의 데이터 전부로 구성원 8개를 학습했습니다.
   - 데이터: e800, dg1, dg2, dgB1~B4
   - 시드: 401~408 (405~408은 `AUG_LC=2`)
   - E8 하나만으로도 0.85 충돌이 6.4%에서 2.9%로 줄었습니다.
3. **DAgger B5 (23만 스텝):**
   - 학생: E8 앙상블
   - 수집 지도: 0.85 지도 워커 3개, 0.7 지도 워커 1개
4. **G8:** 데이터 전부(+B5)로 구성원 8개를 학습했습니다.
   - 시드: 501~508 (505~508은 `AUG_LC=2`)
   - 설정: `EPOCHS=15 LC_WEIGHT=8 LANE_FROM_DG=1`

```bash
LANE_LABEL=best N_WORKERS=4 SEED=851 python tools/rl/dagger_collect.py data/ensE8.pt data/dgB5 60
```

```bash
SEED=501 LANE_FROM_DG=1 EPOCHS=15 LC_WEIGHT=8 python tools/rl/bc_train.py data/g501.pt data/e800.npz data/dg1.npz data/dg2.npz data/dgB1.npz data/dgB2.npz data/dgB3.npz data/dgB4.npz data/dgB5.npz
```

### 해 봤지만 안 쓴 것

- **E8과 G8을 합친 16개 앙상블:** 0.85에서 충돌이 5.5%로 오히려 늘었습니다. 데이터가 다른 두 묶음을 평균하면 차로 변경 시점이 어중간해지는 것으로 보입니다.
- **강화학습 사후학습 (잔차 PPO):** 기본 운전자(E8)를 고정하고, 그 행동에 더할 보정만 보상으로 학습했습니다(`algorithms/residual.py`). 결과는 아래와 같습니다.

  | 시도 | 바꾼 것 | 결과 (0.85, 같은 시드 210회) |
  |---|---|---|
  | res1 | 가감속 보정 + 차로 변경 거부권 | 회전교차로 경로에서 꼭 필요한 차로 변경까지 막음 (완주 1/30) |
  | res2 | 가감속 보정만 | 완주 92.9%, 충돌 4.3% (E8: 92.4%, 1.9%) |
  | res3 | res2 + 매 스텝 TTC 감점 | 완주 92.4%, 충돌 3.3% |
  | res4 | 거부권 + 거부 비용 + 잘못된 차로 감점 10 | 학습 중 차로 갇힘이 10%까지 늘어 중단 |

  충돌은 에피소드의 2~3%에서만 일어납니다. 그래서 200만 스텝을 학습해도 충돌 경험이 50번 남짓이라, 보상만으로 고칠 신호가 부족했습니다. 다음 시도는 충돌 몇 초 전 상태에서 에피소드를 다시 시작하는 방식입니다. 진행 상황은 브랜치 기록을 보세요.
