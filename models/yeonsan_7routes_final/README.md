# 연산교차로 7경로 최종 모델 (모방학습 + DAgger, 16개 앙상블)

> 2026-11-19 · 학습·평가: 호섭 (Claude Code로 진행) · 브랜치 `train/yeonsan-6way`

연산교차로(부산 6지 신호교차로)를 지나는 경로 7개를 운전하는 모델입니다. 같은 구조의 정책 신경망 16개를 평균해서 운전합니다(앙상블).

## 성적 (결정적 정책, 모델 고르는 데 쓰지 않은 교통 시드)

| 교통량 (실측 대비) | 평가 | 완주 | 충돌 | 신호 위반 | 차로 갇힘 | 시간 초과 |
|---|---|---|---|---|---|---|
| 0.5 | 840회 (시드 909~914) | 97.3% | 1.55% | 1.0% | 0.2% | 0 |
| 0.7 (main 지도) | 420회 (시드 921~924) | 96.7% | 1.43% | 0.7% | 1.0% | 0.2% |
| 1.0 | 140회 (시드 921~922) | 87.1% | 5.0% | 2.9% | 5.0% | 0 |

### 주변 신호 수요 분배 + 버스 추가 뒤 (브랜치 `traffic/yeonsan-capacity`, 다시 학습하지 않음)

주변 신호 녹색 시간을 수요에 맞추고(`SIGNAL["demand_split"]`), 실측 버스 204대/시를 실제 버스 차종으로 넣은 지도입니다(`TRAFFIC["demand"]["bus_vehicles"]`).
같은 교통량 0.7에서도 입구 대기가 없어져 실제로 들어오는 차가 약 10% 늘었고, 버스가 더해졌습니다.

| 교통량 | 평가 | 완주 | 충돌 | 신호 위반 | 차로 갇힘 | 시간 초과 |
|---|---|---|---|---|---|---|
| **0.7 + 버스 (지금 기본값)** | 420회 (시드 921~924) | **95.5%** | **1.9%** | 2.1% | 0.5% | 0 |
| 0.85 + 버스 | 420회 (시드 921~924) | 90.2% | 6.4% | 0.7% | 2.4% | 0.2% |

- 0.7은 프로젝트 기준(완주 90% 이상, 충돌 5% 미만)을 넘습니다. 충돌은 NE→SW·E→W에 4회씩입니다.
- 0.85는 충돌이 기준을 넘습니다. E→W의 월드컵대로 진출 구간 차로 변경 중 옆 충돌과 상류 교차로 안 충돌이 많습니다.

교통량 0.7, 경로별 결과는 다음과 같습니다(경로마다 60회).

| 경로 | 완주 | 충돌 | 신호 위반 | 차로 갇힘 | 시간 초과 |
|---|---|---|---|---|---|
| S→W→회전교차로→W→E (3.1 km) | 59 | 0 | 1 | 0 | 0 |
| N→S | 60 | 0 | 0 | 0 | 0 |
| NE→SW | 58 | 0 | 0 | 1 | 1 |
| E→W | 54 | 2 | 2 | 2 | 0 |
| S→N | 60 | 0 | 0 | 0 | 0 |
| SW→N | 55 | 4 | 0 | 1 | 0 |
| W→E | 60 | 0 | 0 | 0 | 0 |

- 학습은 교통량 0.5 데이터로만 했습니다. 0.7에서도 성능이 거의 그대로입니다. 1.0에서는 도로망이 막혀(입구 대기 17%) 성능이 떨어집니다.
- **목표 대비:** 완주 90% 이상, 충돌 5% 미만(프로젝트 평가 기준)은 0.5와 0.7에서 모두 넘었습니다. 팀 목표인 충돌 약 1%에는 조금 못 미칩니다. 충돌은 SW→N과 E→W에 몰려 있습니다.
- 원자료: `eval.json`

### 이전 모델과 비교 (교통량 0.5)

| 모델 | 방법 | 완주 | 충돌 |
|---|---|---|---|
| C0 | PPO 강화학습 | 65% | 6.2% |
| BC | 모방학습 + 앙상블 증류 | 85.0% | 4.1% |
| 8개 앙상블 (중간) | 모방학습 + DAgger(경로 차로 정답) | 97.9% | 1.79% |
| **final (16개)** | 위 8개 + DAgger 3회차 데이터로 학습한 8개 | **97.3%** | **1.55%** |

## 어떻게 만들었나

`models/yeonsan_7routes_BC/README.md`의 방법(전문가 데이터, 교사 보정, 위험 상황 보강)에 **DAgger 차로 정답을 바꾼 것**이 더해졌습니다.

1. **전문가 데이터:** SUMO 운전 모델이 AV를 몰게 하고, 운전자 실수(sigma)는 껐습니다. 800회, 53만 스텝을 모았습니다(`tools/rl/expert_collect.py`).
2. **DAgger 1·2회차:** 초기 BC 학생으로 모은 7만 스텝입니다. 차로 정답은 SUMO 차로 변경 모델의 "바꾸고 싶고 바꿀 수 있음"입니다.
3. **DAgger B1·B2 (이번에 추가):** 차로 정답을 **"경로를 이어 가려면 옮겨야 할 차로"**(`getBestLanes`의 오프셋)로 바꿨습니다. 그쪽이 막혀 있으면 "유지"입니다. 추월 목적 변경이 섞이지 않아서, 회전교차로 입구처럼 미리 오른쪽에 있어야 하는 곳을 배웠습니다.
   - B1: 강화학습으로 다듬은 BC 학생(RB0)으로 15만 스텝을 모았습니다.
   - B2: 그 데이터로 학습한 4개 앙상블을 학생으로 17만 스텝을 모았습니다.
   - 도구: `tools/rl/dagger_collect.py`, `LANE_LABEL=best`
4. **구성원 16개:** 위 데이터 전부(92만 스텝)로 시드만 바꿔 8개를 학습했습니다. 그중 4개는 위험 상황 보강을 넣었습니다(`AUG_LC=2`). 이 8개 앙상블을 학생으로 DAgger B3(19만 스텝)을 더 모으고, 그 데이터까지 넣어 같은 방식으로 8개를 더 학습해 합쳤습니다.
   - 가감속 손실은 다음 스텝 속도 오차이고, 교사 보정(앞차 2 m 여유, 적색 정지선 1 m 앞 정지)을 적용했습니다.
   - 도구: `tools/rl/bc_train.py`
5. **앙상블:** 가감속은 평균, 차로는 확률의 로그 평균에서 가장 큰 쪽을 고릅니다.
   - 증류한 단일 모델은 같은 시드에서 완주 95%, 충돌 4.3%였고, 앙상블은 완주 99%, 충돌 0.7%였습니다. 충돌을 지키려고 앙상블 그대로 씁니다.
   - 8개에서 16개로 늘리니 교통량 0.7에서 충돌이 4.3%에서 1.4%로 줄었습니다(8개는 0.5에서만 잘 맞음).

### 해 봤지만 안 쓴 것

- **교통량 0.7 데이터를 섞어 다시 학습:** 0.7에서 완주 89%로 오히려 나빠졌습니다(16개 앙상블은 0.5 데이터만으로 96.7%).
- **접근 속도 비례 위험 상황 보강:** 충돌 2.9%로 나빠졌습니다.

- **BC 모델에서 강화학습(PPO)으로 이어 학습** (모방학습 손실을 함께 걸어도)
  - 10만 스텝 저장본은 충돌이 BC의 절반(2.3%)이었습니다.
  - 하지만 회전교차로 경로를 놓쳤고, 더 학습하면 충돌이 다시 늘었습니다(6~10%).
- **노면 화살표 5칸(약간 왼쪽 / 크게 왼쪽 구분):** 회전교차로 경로가 나빠졌습니다.


```bash

```

```bash
# DAgger B (차로 정답 best). 학생은 그때까지 가장 좋은 모델 (.pt, 앙상블 .pt, 또는 구성원 경로 목록 .ens)

```

```bash
# 구성원 (시드를 바꿔 8번, 절반은 AUG_LC=2 추가)
SEED=21 LANE_FROM_DG=1 EPOCHS=15 LC_WEIGHT=8 python tools/rl/bc_train.py data/m21.pt data/e800.npz data/dg1.npz data/dg2.npz data/dgB1.npz data/dgB2.npz
```

```bash
# 앙상블 파일로 묶기 (구성원 파일 목록)
python -c "import torch, glob; from algorithms.ensemble import EnsemblePolicy; EnsemblePolicy.save('models/my/model.pt', 56, 2, [torch.load(f) for f in sorted(glob.glob('data/m*.pt'))])"
```

데이터 파일은 용량 때문에 저장소에 넣지 않았습니다(모두 약 20 MB, 위 명령으로 다시 만들 수 있음).

## 공지 관련 확인할 것

- **노면 화살표 관측:** 도로 표시이고, 어느 차로로 가야 하는지는 알려 주지 않습니다.
- **모방학습 방식:** 프로젝트 안내 문서는 "강화학습 / 모방학습"을 모두 허용하고, 3회차 자료에 "Expert Dataset → BC"가 있습니다. 다만 기본은 수업의 강화학습 알고리즘입니다.
- **교사와 학생:** DAgger와 전문가(교사)는 SUMO의 경로 정보를 씁니다. 학습된 AV는 위 관측만 봅니다. 주행 중 보조 규칙은 없습니다.
