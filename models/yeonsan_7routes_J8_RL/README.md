# 연산교차로 7경로 모델 J8_RL (모방학습 J8 + 강화학습 미세조정)

> 2026-11-20 · 브랜치 `traffic/yeonsan-capacity` · 출발점: `models/yeonsan_7routes_J8/`

모방학습만 하면 보상이 학습에 아무 역할을 하지 않습니다. 그래서 모방학습 앙상블 J8을 사전학습으로 두었습니다. 그 위에 **PPO(보상)와 모방학습 손실을 함께 써서** 구성원 8개를 모두 미세조정했습니다.

## 성적 (결정적 정책, 경로마다 시드당 15회)

| 교통량 (실측 대비) | 평가 | 완주 | 충돌 | 신호 위반 | 차로 갇힘 | 시간 초과 |
|---|---|---|---|---|---|---|
| **0.85 + 버스** | 840회 (시드 921~924, 931~934) | **97.4%** | **0.24%** | 1.31% | 1.07% | 0 |
| 0.7 + 버스 | 420회 (시드 921~924) | 94.8% | 1.19% | 3.10% | 0.95% | 0 |

같은 지도, 같은 시드에서 J8(미세조정 전)과 비교한 결과입니다.

| 모델 | 0.85 완주 / 충돌 / 신호 위반 (840회) | 0.7 완주 / 충돌 / 신호 위반 (420회) |
|---|---|---|
| J8 (모방학습만) | 97.0% / 0.60% / 0.60% | **98.1% / 0.48% / 0.48%** |
| **J8_RL (+ PPO 75만 스텝)** | **97.4% / 0.24%** / 1.31% | 94.8% / 1.19% / 3.10% |

- **0.85 교통:** 학습 워커 4개 중 3개가 이 교통량이었습니다. 충돌이 840회 중 5회에서 2회로 줄었고 완주도 조금 올랐습니다.
- **0.7 교통:** 오히려 나빠졌습니다. 주로 신호 위반(13회)이 늘었는데, NE→SW 5회, E→W 4회처럼 여러 경로에 퍼져 있습니다.
  - 강화학습이 조금 더 빨리 달리는 쪽으로 정책을 옮긴 것으로 보입니다. 진행 보상에 비해 신호 위반 감점(20)이 충돌 감점(50)보다 작았습니다.
  - 교통이 적으면 앞차가 속도를 막아 주지 않습니다. 그래서 황색이나 적색 직전에 정지선을 넘는 일이 늘어난 것으로 보입니다.
- **어느 모델을 쓸지:** 두 교통량 모두 프로젝트 기준(완주 90% 이상, 충돌 5% 미만)은 넘습니다. 하지만 두 교통량을 함께 보면 J8이 더 고릅니다. 이 모델은 "보상을 실제로 반영해 정책을 바꾼 강화학습 모델"로 두고, 비교용으로 함께 보관합니다.
- 원자료: `eval.json`

## 어떻게 만들었나

### 정책 구조: 앙상블 전체를 하나의 행동-가치 신경망으로 (`algorithms/ensemble.py`의 `EnsembleActorCritic`)

- **정책:** J8 구성원 8개를 모두 학습 가능한 상태로 둡니다.
  - 가감속 평균: 8개의 평균입니다.
  - 차로 로짓: 8개 log-softmax의 평균입니다.
  - 그래서 평가 때 쓰는 앙상블과 학습하는 정책이 똑같습니다.
- **탐색 잡음:** 가감속 표준편차(log_std)를 하나 공유합니다. 처음 값은 −1.5(약 0.22)입니다.
- **가치 신경망:** 새로 만들었습니다(256-256, Tanh). 처음 20번 업데이트는 가치 신경망만 학습합니다(`VALUE_WARMUP=20`).

### 학습: PPO + 모방학습 손실

- **업데이트 순서:** PPO 업데이트를 한 번 할 때마다 모방학습 손실로 20번 더 업데이트합니다.
  - 모방학습 손실은 가감속 손실과 차로 교차 엔트로피(차로 변경 가중치 8)입니다.
  - 데이터는 DAgger B4~B7 데이터 95.5만 개입니다. 여기에 넓은 차로 변경 보강 "유지" 복사본을 더했습니다(`tools/rl/make_bcdata.py`).
  - 이 손실이 정책을 SUMO 전문가 근처에 묶어 둡니다. 강화학습이 잘 하던 운전을 잊지 않게 합니다.
- **학습률:** 1e-5입니다. 3e-5 이상에서는 처음 몇십 번 업데이트에서 성적이 크게 흔들렸습니다.
- **보상** (`train.py` 기본값에서 바꾼 것):
  - 충돌 −50, 신호 위반 −20, 잘못된 차로 −10
  - TTC 감점 0.3
  - 충돌 감점이 10이면 에피소드당 진행 보상(약 22)보다 싸서, 정책이 더 빨리 달리는 쪽으로 갔습니다.
- **위험 상황 재시작:** 새 에피소드의 20%는 충돌 약 12스텝 전 SUMO 저장 상태에서 다시 시작합니다(`DANGER_P=0.2`, `RING_N=6`). 충돌은 에피소드의 몇 %에서만 나서, 그냥 학습하면 충돌을 겪을 기회가 너무 적기 때문입니다.
- **환경:** 워커 4개입니다. 0.85 교통 지도 3개, 0.7 교통 지도 1개를 썼습니다. 4096 스텝마다 업데이트했고, 업데이트 한 번에 약 50초가 걸렸습니다.

```bash
python tools/rl/make_bcdata.py data/bc_ft.npz data/dgB4.npz data/dgB5.npz data/dgB6.npz data/dgB7.npz
```

```bash
INIT_ENSEMBLE=models/yeonsan_7routes_J8/model.pt BC_DATA=data/bc_ft.npz BC_W=1 BC_STEPS=20 BC_BATCH=512 \
LR=1e-5 INIT_LOG_STD=-1.5 LANE_ENT=0 VALUE_WARMUP=20 DANGER_P=0.2 RING_N=6 TIMESTEPS=1000000 SNAP_EVERY=250000 SEED=21 \
REWARD_PATCH='{"collision_penalty": 50.0, "red_light_penalty": 20.0, "wrong_lane_penalty": 10.0, "ttc_penalty": 0.3}' \
MAX_STEPS=3000 LANE_PLAN_RANGE=300 OBS_VISIBILITY=100 LANE_ARROWS=1 INTERNAL_OBS=1 \
python tools/rl/residual_train.py ft1
# 결과: results/ft1/ens_753k.pt = 이 모델
```

## 그 전에 해 본 강화학습: 잔차 PPO (res1~res9)

먼저 기본 운전자(모방학습 앙상블)를 고정했습니다. 그리고 그 가감속에 더할 작은 보정과 차로 변경 거부권만 PPO로 학습했습니다(`algorithms/residual.py`).

| 시도 | 바꾼 것 | 결과 (0.85) |
|---|---|---|
| res1 | 가감속 보정 + 차로 변경 거부권 | 회전교차로 경로에서 꼭 필요한 차로 변경까지 막음 |
| res2 / res3 | 가감속 보정만 (+ TTC 감점) | 충돌이 기본 운전자보다 늘어남 (4.3%, 3.3%. 기본 1.9%) |
| res4 | 거부권 + 거부 비용 | 학습 중 차로 갇힘 10% |
| res5~res9 | 최대 거부 길이 제한(`MAX_VETO=6`), 위험 상황 재시작, 보정 크기 비용 | 어느 것도 기본 운전자보다 나아지지 않음 |

실패한 이유는 세 가지였습니다.
- 충돌 감점이 진행 보상에 비해 너무 쌌습니다.
- 기본 운전자가 이미 아주 강했습니다.
- 보정만 학습하는 구조로는 차로 변경 판단을 고칠 수 없었습니다.

그래서 이번에는 앙상블 전체를 미세조정했습니다. 모방학습 손실로 정책을 붙잡아 두는 방식입니다.
